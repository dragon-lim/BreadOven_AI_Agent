# Bakery Inventory AI Agent

베이커리 작업장의 재고와 매일의 생산 계획을 분석하여 재료 재고 관리와 발주 업무를 자동화·지원하는 AI Agent 프로젝트입니다.

### 프로젝트를 계획한 이유

저는 약 2년 반 동안 베이커리에서 근무한 경험이 있습니다. 그중 특히 익숙해지기까지 시간이 많이 걸렸던 업무 중 하나가 재고 관리였습니다.

베이커리에서는 생산하는 제품마다 필요한 재료가 다릅니다. 매일 근무가 끝나기 전, 매장에 있는 재료와 물품의 재고량을 하나씩 확인하고 기록했습니다. 매장을 돌아다니며 현재 재고량을 확인하는 데 많은 시간과 노동이 필요했습니다.

또한 현재 재고량뿐만 아니라 다음 날의 생산 계획과 각 제품의 레시피에 필요한 재료량을 함께 고려하여 매일 발주서를 작성해야 했습니다.

재고 관리에서는 재고량뿐만 아니라 각각의 재료의 유통기한도 함께 고려해야 합니다. 하지만 사람의 기억이나 기록에만 의존하여 관리하는 것에는 한계가 있었고, 유통기한이 지난 재료를 폐기하는 등 불필요한 손실이 발생하기도 했습니다.

이러한 실제 업무 경험을 바탕으로, 현재 공부하고 있는 AI Agent 기술을 활용하면 재고 관리와 발주 업무를 보다 효율적으로 지원할 수 있겠다는 생각으로 이 프로젝트를 계획했습니다.

이 프로젝트는 AI Agent가 매장의 현재 재고 상태와 매일의 생산 계획을 분석하여 **추가 발주가 필요한 재료를 판단하고, 유통기한이 임박한 재료는 가까운 주말이나 행사에 활용할 수 있는 제품을 제안하는 것**을 목표로 합니다.

단순히 정해진 기준에 따라 재고를 계산하는 시스템이 아니라, 여러 정보를 종합하여 다음 행동을 판단하는 **AI Agent 기반 재고 관리 시스템**을 구현하는 것을 목표로 합니다.


## 주요 기능

* 바코드를 활용한 재료 및 물품 정보 관리
* 현재 재고량 확인 및 관리
* 제품별 생산 계획 관리
* 레시피를 기반으로 필요한 재료량 계산
* 재고량과 생산 계획을 비교하여 발주 필요 여부 판단
* 유통기한이 임박한 재료 확인
* 유통기한이 임박한 재료를 활용할 수 있는 제품을 가까운 주말이나 행사 일정에 맞춰 추천
* 발주서 자동 갱신 및 관리


## AI Agent의 역할

AI Agent는 재고, 생산 계획, 레시피, 유통기한 등의 정보를 종합하여 다음 행동을 판단합니다.

1. 현재 재고량 확인
2. 예정된 생산량과 그에 따른 필요한 재료량 분석
3. 생산 계획을 고려한 재고 부족 여부 판단
4. 발주가 필요한 재료와 수량 판단
5. 현재 재고의 유통기한 및 재고 상태 확인
6. 유통기한이 임박한 재료를 활용할 수 있는 제품을 행사 일정 등을 고려하여 제안
7. 판단 결과에 따라 발주서 갱신


## 사용하는 데이터

본 프로젝트에서는 다음과 같은 정보를 활용합니다.

* 재료명
* 현재 재고량
* 최소 재고 기준
* 유통기한
* 제품별 레시피
* 예정 생산량
* 발주 단위
* 거래처 정보 및 품목
* 매일 생산하는 제품의 생산량
* 행사 일정 (Google Calendar 연동)


### 데이터 활용 예시

**재고 품목: 말차 파우더**

* 현재 재고: 5봉
* 말차 생크림빵 생산 예정: 10개
* 제품 10개 생산에 필요한 말차 파우더: 3봉

Agent가 생산 계획과 현재 재고를 비교하여 생산 후 예상 재고량을 계산합니다.

또한 이후의 생산 계획과 최소 재고 기준 등을 고려하여 추가 발주가 필요한지 판단합니다.

---

**재고 품목: 생크림**

* 현재 재고: 10팩
* 유통기한: 2일 후
* 생산 계획 기준 소비 예상량: 4팩

Agent가 남은 6팩을 2일 안에 소진하기 어렵다고 판단하고,
이번 주말 행사 일정을 확인하여 생크림을 주재료로 사용하는
케이크·크림빵 등의 제품을 추가 생산 제안합니다.

---

**발주 판단: 버터**

* 현재 재고: 2kg
* 내일 생산 계획 기준 필요량: 3kg
* 최소 재고 기준: 1kg

Agent가 현재 재고로는 내일 생산량을 충당할 수 없다고 판단하여
자동으로 발주 목록에 버터를 추가하고 발주서를 갱신합니다.

## 기술 스택

> 개발 진행에 따라 업데이트 예정

* **언어**: Python
* **AI / Agent**: LangChain 또는 LangGraph + OpenAI API (또는 동급 LLM API)
* **바코드**: pyzbar / python-barcode
* **데이터**: CSV → SQLite (단계적 전환 예정)
* **외부 연동**: Google Calendar API
* **Web**: FastAPI 또는 Streamlit (UI 구성 시)
