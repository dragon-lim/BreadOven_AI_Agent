# Bakery Inventory AI Agent

ベーカリーの作業場における在庫と日々の生産計画を分析し、原材料の在庫管理や発注業務を自動化・支援するAI Agentプロジェクトです。

[🇰🇷 한국어 README](README_ko.md)

## プロジェクト概要

### プロジェクトを計画した理由

私は約2年半、ベーカリーで勤務した経験があります。その中で、特に慣れるまでに時間がかかった業務の一つが在庫管理でした。

ベーカリーでは、製造する商品ごとに必要な原材料が異なります。毎日の勤務終了前には、店舗にある原材料や商品の在庫数を一つずつ確認し、記録していました。店舗内を回りながら現在の在庫量を確認するには、多くの時間と労力が必要でした。

さらに、現在の在庫量だけでなく、翌日の生産計画や各商品のレシピに必要な原材料の量を考慮しながら、毎日発注書を作成する必要がありました。

在庫管理では、在庫量だけでなく、それぞれの原材料の賞味期限・使用期限も考慮する必要があります。しかし、人の記憶や記録だけに頼って管理することには限界があり、期限切れによる廃棄など、不要な損失が発生することもありました。

こうした実務経験から、現在学んでいるAI Agentの技術を活用することで、在庫管理や発注業務をより効率的に支援できるのではないかと考え、本プロジェクトを計画しました。

本プロジェクトでは、AI Agentが店舗の現在の在庫状況と日々の生産計画を分析し、**追加発注が必要な原材料を判断するとともに、使用期限が近い原材料については、近い週末やイベントで活用できる商品を提案すること**を目指します。

単純に決められた基準に従って在庫数を計算するだけではなく、複数の情報を組み合わせて次に取るべき行動を判断する、**AI Agentベースの在庫管理システム**の実現を目指します。

## 主な機能

* バーコードを利用した原材料・物品情報の管理
* 現在の在庫量の確認・管理
* 商品ごとの生産計画の管理
* レシピをもとにした必要原材料量の計算
* 在庫量と生産計画を比較した発注の必要性の判断
* 使用期限が近い原材料の確認
* 使用期限が近い原材料を活用できる商品を、近い週末やイベントの日程に合わせて提案
* 発注書の自動更新・管理

## AI Agentの役割

AI Agentは、在庫・生産計画・レシピ・使用期限などの情報を組み合わせ、次に取るべき行動を判断します。

1. 現在の在庫量を確認
2. 予定されている生産量と、それに必要な原材料量を分析
3. 生産計画を考慮して在庫不足の有無を判断
4. 発注が必要な原材料と数量を判断
5. 現在の在庫の使用期限と在庫状況を確認
6. 使用期限が近い原材料を活用できる商品を、イベントや販売予定などを考慮して提案
7. 判断結果に基づいて発注書を更新

## 使用するデータ

本プロジェクトでは、以下のような情報を利用します。

* 原材料名
* 現在の在庫量
* 最低在庫基準
* 使用期限
* 商品ごとのレシピ
* 予定生産量
* 発注単位
* 取引先情報
* イベント・販売予定

### データ活用例

**在庫品目：抹茶パウダー**

* 現在の在庫：5袋
* 抹茶生クリームパンの生産予定：10個
* 10個の生産に必要な抹茶パウダー：3袋

Agentは生産計画と現在の在庫を比較し、生産後の予想在庫量を計算します。

さらに、その後の生産計画や最低在庫基準などを考慮し、追加発注が必要かどうかを判断します。

## プロジェクトの目標

ベーカリーや小規模事業者で繰り返し発生する在庫確認や発注業務を自動化し、在庫量・生産計画・レシピ・使用期限・イベント予定などの複数の情報を総合的に分析して、次に取るべき行動を判断できる**実用的なAI Agentシステム**を実現することを目標とします。
